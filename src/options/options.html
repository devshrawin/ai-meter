AI Meter settings

General

Other AI sites

Add any AI chat site that isn't built in. Chrome asks for access to that one site only. AI Meter then counts your sends there (estimate), and watches for the site's own limit notices and rate-limit errors.

    Estimate rules

    Where a site doesn't publish usage numbers, AI Meter counts your sends locally and compares against these limits. Sites with real numbers only use these as a fallback. Rules are matched top to bottom against the model name; first match wins. Limit 0 means "just count". Set these to match your plan.

    Debug

    Stores the last 60 matching requests/responses locally. Request bodies (your prompts) are never stored.
