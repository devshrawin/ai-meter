AI Meter settings

General

Estimate rules

ChatGPT and Gemini don't publish usage numbers, so AI Meter counts your sends locally and compares against these limits. Rules are matched top to bottom against the model name; first match wins. Limit 0 means "just count". Set these to match your plan.

Debug

Stores the last 60 matching requests/responses locally. Request bodies (your prompts) are never stored.
