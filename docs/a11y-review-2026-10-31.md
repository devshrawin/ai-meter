# Visual and accessibility pass: AI Meter (Stage 4)

Date: 2026-10-31. Surfaces: the on-page pill and panel, the toolbar popup, the options page. Lavender look kept. Method: code read of all three surfaces, a computed contrast table (WCAG 2.2 AA, 4.5:1 text, 3:1 non-text), and runtime checks of keyboard use and accessible names in a browser against preview harnesses (`tools/a11y-preview`, `tools/popup-preview`). Before/after screenshots are in `dist/a11y-before/` and `dist/a11y-after/`.

Not run: axe-core (loading it into the page was not allowed in this session), a real screen reader (NVDA / VoiceOver), Windows high-contrast mode.

## Issues and fixes

| # | Sev | Surface | Issue | Fix |
|---|---|---|---|---|
| 1 | High | Pill | A `div` with pointer handlers only: not focusable, no role, no name. Keyboard and screen-reader users could not open it. | `role="button"`, `tabindex="0"`, `aria-expanded`, and an `aria-label` that speaks the state ("Claude: 32% used, resets in 3h 12m. Show details"). Enter / Space toggles, Escape closes. |
| 2 | High | Pill | Dragging was the only way to move it. | Shift + arrow keys move it 16 px and save the position. |
| 3 | Med | Panel | Panel came before the pill in the DOM, so Tab hit its buttons first. No region name. Bars had no semantics. | DOM order is pill then panel (CSS `column-reverse` keeps the panel visually above). Panel is `role="region"` with a name; each bar is a `progressbar` with value and reset text; counters without a percentage are hidden from AT. |
| 4 | Med | All | Text contrast failures (light mode): accent links 3.0:1, amber text 2.2:1, REAL / EST tags 3.3–3.4:1, stale cards at 72% opacity 2.9:1, cache timer green 2.3:1. | Darker text-only tokens (`--accent-text #6f52c9` 5.2:1, `--warn-text #b45309` 5.0:1, `--ok-text #15803d`, tag mix 40%). Stale cards no longer fade; they get a dashed border, grey name and the "stale" text. Bright status colours stay for LEDs and bars. Dark mode already passed except stale (fixed with the same change). |
| 5 | Med | Popup | A re-render every 30 s (and on every usage update) dropped keyboard focus from the card you were on. | Focus returns to the same card's header after each render. |
| 6 | Med | Options | Four inputs had only placeholders (site, limit, window, thresholds); every estimate-rule input and the remove and add buttons had no usable name; no `th scope`; no viewport meta. | Every control now has a name (96 of 96 verified), `scope="col"`, viewport meta added. |
| 7 | Med | Options | Saved / error messages were silent; the Iris options stayed focusable while "off". | `#status` is a polite live region; Iris options are properly `disabled` when Iris is at home. |
| 8 | Low | All | No visible focus ring on the pill, problem button, add-site, options controls. | Focus rings in the accent-text colour (3:1+). |
| 9 | Low | All | Animations ignored `prefers-reduced-motion` (LED pulse, bar transitions, chevron). Iris already honours it. | Reduced-motion rules on all three surfaces. |
| 10 | Low | Popup | "+ Add site" was a link acting as a button. LED, mini bar and chevron were read out as noise. | Real button; decorative elements are `aria-hidden`; "Copy debug log" confirmations are announced. |
| 11 | Low | Pill | Iris was exposed to screen readers as a clickable thing. | `aria-hidden` (she is decoration; the numbers are in the pill). |

## Left as is (on purpose)

- **Bar and LED fills vs their track** are 1.8–2.3:1. They are not the only carrier of the information: every bar sits beside its percentage in text and every LED beside its name and value, so WCAG 1.4.11 does not require 3:1 there. Kept the pearl-lavender look.
- **Panel and popup text sizes (10–12 px)** are small but pass contrast and scale with browser zoom. Not changed, to keep the layout.
- **Options page keeps its neutral palette.** It passes contrast; recolouring it is a design choice, not an accessibility fix.

## Verified at runtime

- Pill: role, tabindex 0, spoken label, `aria-expanded` flips, Enter opens, Escape closes, Shift + arrow moves it, panel region and progressbars read correct values, Iris `aria-hidden`.
- Popup: focus kept across re-render, bars announce, no unnamed buttons / summaries / links, decorative nodes hidden.
- Options: 96 of 96 controls named, status is a live region, viewport meta present, Iris options disabled when she is at home.
- Tests: 147 pass (4 new for the pill: label and button semantics, keys, panel and progressbars, decorative and status).

## Not verified

- A real screen reader, high-contrast mode, 200% browser zoom on the options page, and the pill on a site that has its own `:focus` or overlay styles.
